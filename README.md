# 📚 StudyForge AI

> Multi-agent Gemini application that generates interactive study ebooks with rich diagrams, quizzes, and self-contained HTML downloads.

## ✨ Features

- **AI-Powered Ebook Generation** — Enter any topic and get a fully structured, multi-chapter study ebook generated by Gemini AI.
- **Multi-Agent Showcase** — Watch the generation pipeline in real-time as specialized AI agents (Researcher, Writer, Diagrammer, Quiz Maker) collaborate.
- **Interactive Quizzes** — Auto-generated quizzes embedded within chapters to test your understanding.
- **Rich Diagrams** — AI-generated Mermaid diagrams and visual aids to explain complex concepts.
- **Markdown Rendering** — Beautiful rendering with LaTeX math support via KaTeX.
- **HTML Download** — Export any ebook as a fully self-contained HTML file for offline reading.
- **Preset Gallery** — Browse pre-built sample ebooks to explore instantly.
- **Smooth Animations** — Polished UI with Framer Motion transitions throughout.

## 🚀 Getting Started

### Prerequisites

- **Node.js** v18+ (or [Bun](https://bun.sh/))
- A **Gemini API key** — get one at [Google AI Studio](https://aistudio.google.com/)

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/your-username/studyforge-ai.git
   cd studyforge-ai
   ```

2. **Install dependencies**

   ```bash
   npm install
   # or
   bun install
   ```

3. **Configure environment variables**

   ```bash
   cp .env.example .env
   ```

   Open `.env` and set your Gemini API key:

   ```env
   GEMINI_API_KEY="your_gemini_api_key_here"
   ```

4. **Start the dev server**

   ```bash
   npm run dev
   ```

   The app will be available at **http://localhost:3000**.

### Production Build

```bash
npm run build
npm start
```
